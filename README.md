# Deuda Inteligente v3 (diseño Stitch)

Landing clara con simulador "comprar vs alquilar" + venta del Sentinel (S/ 14.30) + guía PDF.
Cada HTML funciona solo (doble clic para probar).

## Antes de publicar
1. En `index.html` busca "CONFIGURACIÓN" y completa tus datos (WhatsApp, Yape, titular, RUC, dirección, correo).
2. Haz lo mismo en `libro-de-reclamaciones.html` (busca "CONFIGURACIÓN").
3. Opcional: sube `og-image.jpg` (1200x630) para la vista previa al compartir el link.

## Netlify (desde GitHub)
- Publish directory: `.` y sin build command.
- Activa Forms: aparecerán `pedido` y `libro-reclamaciones`. Agrega tu correo en Forms > Notifications.
